# «Ну, погоди!» — Электроника ИМ-02 в браузере

Веб-версия легендарной советской карманной игры 1984 года. Корпус, кнопки и жидкокристаллический экран
нарисованы с нуля на CSS и SVG: ни одной сторонней картинки, всё масштабируется без потери качества.

## Вселенная

Четыре курицы на насестах без устали несут яйца, и яйца катятся по жёлобам. Волк в кепке мечется с корзиной между
четырьмя жёлобами и старается поймать каждое. Мимо корзины — яйцо разбивается, из него выбегает цыплёнок.
Три сбежавших цыплёнка — и игра окончена. Иногда в окошке выглядывает Заяц: пока он смотрит, промах считается
только за половинку (иконка цыплёнка мигает). На 200 и 500 очках все промахи прощаются, как в оригинале.

## Запуск

```bash
npm ci          # установка зависимостей
npm run dev     # дев-сервер на http://localhost:8080
npm run build   # сборка бандла в dist/
npm test        # юнит-тесты (Vitest)
npm run lint    # ESLint + Prettier
npm run typecheck
```

## Управление

| Действие              | Клавиатура                             | Мышь / тач                        |
| --------------------- | -------------------------------------- | --------------------------------- |
| Корзина ↖ ↙ ↗ ↘       | `Q` `A` `P` `L` (а также `W S O K`, Numpad `7 1 9 3`) | красные кнопки на корпусе |
| Корзина относительно  | стрелки: ←/→ — сторона, ↑/↓ — высота   | —                                 |
| Игра А / Игра Б       | `1` / `2`                              | кнопки «ИГРА А» / «ИГРА Б»        |
| Ещё раз               | `Enter`                                | кнопки в окне проигрыша           |
| Пауза                 | `Пробел` / `Esc`                       | «ПАУЗА» на тач-пульте, тап по окну паузы |
| Звук                  | `M`                                    | кнопка «ЗВУК»                     |
| Часы                  | `T`                                    | кнопка «ВРЕМЯ»                    |

Клавиши привязаны к физическим кнопкам (`KeyboardEvent.code`), поэтому играть можно и на русской раскладке.

## На что обратить внимание

- **Настоящий ЖК.** Все сегменты (4 позы Волка, 20 положений яиц, цыплята, Заяц, цифры «88:88») всегда есть на
  экране, но погашенные едва видны — как на реальном экране «Электроники». У включённых сегментов есть тень на
  подложке и задержка отклика 70 мс, на стекле — блик. Под ЖК лежит приглушённая цветная «напечатанная»
  подложка: курятник, насесты, жёлобы, окошко.
- **Яйцо катится.** На каждой позиции жёлоба сегмент яйца повёрнут по-своему, поэтому видно вращение.
- **Состояния игры:** стартовый экран с демо-режимом (автопилот играет сам, на табло идут часы) → игра → пауза →
  экран проигрыша со счётом и рекордом.
- **Звук без файлов.** «Пищалка» синтезируется через Web Audio (прямоугольная волна). У каждого жёлоба свой тон,
  поэтому на слух понятно, откуда катится яйцо. Отдельные мелодии на старт, бонус, промах и конец игры. Мелодии
  свои, не из мультфильма.
- **Честная сложность.** Два яйца никогда не скатываются в одно и то же время, поэтому каждое можно поймать в
  принципе (это проверяет тест на 5000 тактов). Скорость растёт «пилой»: внутри сотни разгон, после сотни
  небольшая передышка.
- **Мобильные.** Кнопки реагируют на `pointerdown` — мгновенно и одинаково для мыши, пальца и стилуса. В
  портретной ориентации под корпусом появляется большой пульт. При промахе телефон вибрирует. Если свернуть
  вкладку, игра встаёт на паузу.
- **Рекорды** для игр А и Б и настройка звука сохраняются в `localStorage`.

## Архитектура

```
src/
  index.ts, Init.tsx      точка входа
  App/                    приложение
    App.tsx
    hooks/                хуки, нужные только App
      useGame/            игровой цикл (rAF), демо-режим, рекорды, автопауза
      useControls/        нажатия → действия игры с учётом состояния
      useKeyboard, useSound, useFitScale, usePressFlash, useNow
    components/           компоненты, нужные только App
      Device/             корпус ИМ-02
        components/       Bezel, BigButton, ServiceButtons
      Lcd/                SVG-экран
        components/       Segment, Wolf, Eggs, Chick, CrashScene, Hare, Misses, Scoreboard, Underlay…
      Overlay/            экраны поверх ЖК
        components/       StartScreen, PauseScreen, GameOverScreen, ScreenPanel, ModeButtons, Hint
      TouchPad/           крупный пульт для телефона
      Stage/              масштабирование корпуса под окно
    utils/                вспомогательные функции App
  components/             общие компоненты (PressButton — кнопка на pointerdown)
  engine/                 чистая логика: tick(state, random, config) → { state, events }
    tick/                 такт: яйца, приземление, спавн, Заяц, анимация промаха
  config/                 параметры игры, раскладка клавиш, звуки
  types/                  общие типы
  audio/                  синтез звука, реагирует на события движка
  storage/                рекорды и настройка звука в localStorage
  styles/                 глобальные стили, LESS-переменные и миксины
  utils/                  форматирование табло, безопасный localStorage, вибрация, seeded random
```

Правило раскладки: у каждого компонента своя папка (`Comp.tsx`, `Comp.module.less`, `index.ts`). Если
компонент или хук нужен только одному месту, он лежит в его папке `components/` или `hooks/`; общее для
нескольких мест поднимается выше. Импорты общих модулей — абсолютные от `src` (`engine`, `config/…`,
`types/…`), это настроено в `tsconfig.json` (`baseUrl`), `webpack.config.js` (`resolve.modules`) и
`vitest.config.mts`. Тесты лежат рядом с кодом, который проверяют.

Движок не знает про React, таймеры и звук: он получает состояние и возвращает новое плюс список событий
(`catch`, `miss`, `bonus`, `gameOver`…). Поэтому логику легко тестировать, а звук и вибрация просто
подписаны на события. Конфиг передаётся в движок параметром, и тесты подставляют свой, без случайностей.

## Что поправлено в бойлерплейте

- ESLint-конфиг ссылался на пакеты, которых не было в `package.json` (`@babel/eslint-parser`,
  `@babel/eslint-plugin`, `@typescript-eslint/*`, `eslint-plugin-security`), и линтер не запускался. Пакеты
  добавлены.
- `@typescript-eslint` 6 официально поддерживал TypeScript только до 5.3 и предупреждал при каждом запуске линтера.
  Обновлён до 8.x (вместе с ESLint 8.38 → 8.57, мажорная версия та же); правило `ban-types` в
  `config/eslint/internal/typescript.js` переименовано в `no-restricted-types` — так оно называется в новой версии.
- В `tsconfig.json` было `lib: ["DOM", "ES5"]`, из-за чего `tsc` ругался на `Array.includes`, `Set` и прочее.
  Теперь `ES2021` + `DOM.Iterable`. Добавлены `rootDir` и `paths` для абсолютных импортов от `src` (без
  устаревшего `baseUrl`), так что проект проверяется без ошибок и в TypeScript 6–7, которым пользуется VS Code.
- В `webpack.config.js` добавлен `resolve.modules: [src, node_modules]` — для тех же абсолютных импортов.
- В `.vscode/settings.json` `eslint.workingDirectories` указывал на папку выше проекта — теперь `auto`. Добавлены
  рекомендации расширений Prettier и ESLint (`.vscode/extensions.json`).
- Добавлены скрипты `test`, `test:watch`, `lint`, `lint:fix`, `format`, `typecheck` и Vitest.
